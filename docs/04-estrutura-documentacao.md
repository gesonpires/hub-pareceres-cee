# 04 - Estrutura de documentação sugerida no repositório

## Arquivos recomendados

1. `README.md`
   - visão geral do problema;
   - objetivo do MVP;
   - links para documentos de produto e técnicos;
   - instruções rápidas de execução local.

2. `docs/01-mvp-perguntas-essenciais.md`
   - checklist de decisões pendentes para fechar escopo.

3. `docs/02-modelo-dados-inicial.md`
   - entidades, campos, relacionamentos e regras de integridade.

4. `docs/03-fluxo-telas-mvp.md`
   - jornada do usuário e definição das telas do MVP.

5. `docs/05-regras-geracao-texto-atos.md` (próximo passo)
   - regras definitivas de ordenação e formatação do bloco;
   - exemplos oficiais de saída;
   - casos-limite (sem atos, atos revogados, duplicidades).

6. `docs/06-backlog-fase-2.md` (próximo passo)
   - backup local automático;
   - geração automática de DOCX “ANÁLISE” via template;
   - critérios de priorização e dependências.

## Convenções úteis

- Nomear documentos com prefixo numérico para leitura orientada.
- Manter seção “Decisões tomadas” e “Pendências” em cada documento.
- Atualizar `README.md` sempre que entrar um novo artefato-chave.
